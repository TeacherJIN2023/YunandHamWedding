# 성진 ♥ 지우 모바일 청첩장

2027년 3월 27일 토요일 낮 12시 · 그래비티 조선 서울 판교 오토그래프 컬렉션

빌드 도구 없이 HTML/CSS/JS만으로 만든 정적 사이트예요. GitHub Pages에 그대로 올리면 됩니다.

## 파일 구조

```
index.html        페이지 뼈대 + 공유 미리보기(OG) 설정
js/config.js      ★ 이름·날짜·계좌·문구 등 내용은 여기만 수정
js/main.js        화면 생성/기능 (보통 건드릴 일 없음)
css/style.css     색상·글꼴·레이아웃
images/           사진 (임시 이미지 → 같은 파일명으로 덮어쓰기)
audio/            배경음악 파일 (선택)
```

## 사진 교체

`images/` 안의 임시 파일을 **같은 이름**으로 덮어쓰면 끝이에요.

| 파일 | 용도 | 권장 크기 |
|---|---|---|
| `cover.jpg` | 첫 화면 (세로 사진) | 1080×1920 |
| `wide.jpg` | 인사말 뒤 전체화면 사진 | 1080×1920 |
| `gallery-01.jpg` ~ `gallery-12.jpg` | 갤러리 | 세로 3:4, 폭 800~1200px |
| `og.jpg` | 카톡 공유 미리보기 | 1200×630 |

용량이 크면 느려져요. 사진 한 장당 300~500KB 이하로 줄여 올리는 걸 권장해요.

## GitHub Pages로 배포

1. GitHub에서 새 저장소(Repository) 생성 (예: `wedding`)
2. 이 폴더의 내용을 저장소에 올리기 (웹에서 *Add file → Upload files* 로 드래그해도 돼요)
3. 저장소 *Settings → Pages → Build and deployment* 에서
   Source: **Deploy from a branch**, Branch: **main / (root)** 선택 후 Save
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소명>/` 주소로 접속 가능

> 저장소가 Public이어야 무료 Pages를 쓸 수 있어요. 올린 사진도 주소를 아는 사람에겐 보이니, 공개해도 괜찮은 사진만 올려주세요.
> 주소를 추측하기 어렵게 저장소 이름을 길게 짓는 방법도 있어요.

## 카카오톡 공유 미리보기 (배포 후 꼭 한 번)

`index.html` 맨 위의 두 줄을 **https://로 시작하는 전체 주소**로 바꿔주세요.

```html
<meta property="og:image" content="https://<아이디>.github.io/<저장소명>/images/og.jpg">
<meta property="og:url"   content="https://<아이디>.github.io/<저장소명>/">
```

카톡은 미리보기를 캐시해요. 바꾼 뒤에도 옛날 모습이 보이면
[카카오 공유 디버거](https://developers.kakao.com/tool/debugger/sharing)에서 해당 주소를 초기화하세요.

## 나중에 채울 것들 (config.js)

- 혼주 성함·연락처 → 인사말 아래 '연락하기' 버튼이 생겨요
- `venue.hall` → 예식 홀 이름·층
- `rsvpUrl` → 구글 폼 링크를 넣으면 '참석 여부 전달' 섹션이 생겨요
- `guestSnapUrl` → 구글 드라이브 업로드 폼 링크를 넣으면 '게스트스냅' 섹션이 생겨요
- `accounts` → 신랑측/신부측 계좌 (복사 버튼 자동 생성)
- `directions` → 오시는 길·주차 안내 (식장 안내 확인 후 수정)
- `closing.wreathNotice` → 화환 안내 문구
- 값이 비어 있는 항목은 화면에서 자동으로 숨겨져요.

## 배경음악

1. `audio/` 폴더에 mp3를 넣고 `config.js`의 `music.src`에 경로를 적어요. (예: `"audio/bgm.mp3"`)
2. 브라우저 정책상 자동재생이 막혀 있어서, 하객이 화면을 처음 터치할 때 재생돼요. 우측 상단 스피커 버튼으로 끌 수 있어요.

**저작권 주의:** 시중 음원(상업 곡)을 공개 저장소에 올려 불특정 다수에게 재생시키면 저작권 문제가 될 수 있어요.
저작권 걱정 없는 무료 BGM(예: 유튜브 오디오 라이브러리, Pixabay Music 등 라이선스 확인)을 쓰거나,
원하는 곡이 있다면 음원 서비스의 청첩장용 제공 방식이나 라이선스 조건을 먼저 확인해 보세요.

## 로컬에서 미리보기

폴더에서 `python3 -m http.server 8000` 실행 후 브라우저에서 `http://localhost:8000` 접속.
(파일을 그냥 더블클릭해서 열어도 대부분 동작해요.)

## 알아둘 점

- 지도는 API 키 없이 쓰려고 티맵/카카오맵/네이버지도 **검색 링크 버튼**으로 만들었어요.
  지도를 화면에 직접 넣고 싶으면 네이버/카카오 지도 API 키가 필요해요.
- 스크롤은 화면 한 장씩 멈추는 방식(scroll snap)이에요. 오시는 길처럼 한 화면보다 긴 섹션은 안에서 자유롭게 스크롤돼요.
- 오시는 길의 지하철 안내(판교역 3번 출구 도보 약 3분)는 인터넷 정보 기준이니, 식장 안내와 맞는지 꼭 확인해 주세요.
